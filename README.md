# Alder Demilade Elizabeth - Birthday Celebration

A responsive, interactive birthday celebration web app for Alder Demilade Elizabeth.

## Features
- Confetti celebration animation
- Photo and video gallery with lightbox view
- Interactive flip cards for birthday wishes and notes (saved locally)
- Mobile-friendly responsive design
